# Aegis US recession monitor

Live page: https://steveudd-afk.github.io/aegis-recession-monitor/

Six recession warning lights with rules fixed in advance and tested on every US recession since 1976, plus a stage-by-stage roadmap of a 2027 bear scenario (AI credit crisis, rising rates, falling home prices) checked against live data. Updated each weekday from FRED, Treasury and Cboe data plus labeled secondary sources.

- Plain-text summary for AI agents: [llms.txt](https://steveudd-afk.github.io/aegis-recession-monitor/llms.txt)
- Daily editions feed: [feed.xml](https://steveudd-afk.github.io/aegis-recession-monitor/feed.xml)

Research, not investment advice.
